## Per-Post Checklist

For each post, run these commands in order:

- [ ] `/seo-research <slug>` — Deep research via Perplexity
- [ ] `/seo-brief <slug>` — Generate content brief from research
- [ ] `/seo-write <slug>` — Write full blog post
- [ ] `/seo-optimize <slug>` — SEO quality check (target: 80+)
- [ ] Upload cover image to Sanity (from `covers/` folder)
- [ ] `/seo-publish <slug>` — Push to Sanity, publish live

## Daily Workflow (15-20 min per post)

```
1. Run /seo-daily → auto-picks next post
2. /seo-research → paste Perplexity results (or API auto)
3. /seo-brief → review outline, approve
4. /seo-write → review draft, edit if needed
5. /seo-optimize → check score, fix any issues
6. /seo-publish → push to Sanity as draft → publish live
7. Update pipeline.yaml status
```
